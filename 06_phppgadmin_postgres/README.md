# связка phppgadmin + postgresql с сетевой изоляцией (задание 8)

проект решает задачу развертывания веб-интерфейса phppgadmin в паре с СУБД PostgreSQL в изолированной сетевой среде.

## разбор примечания из методички («в случае проблем пропустить»)

в методичке указано: *«в случае проблем с подключением к субд из phppgadmin, задание пропустить»*.  
проблемы обычно возникают по двум причинам:
1. **метод шифрования паролей:** начиная с PostgreSQL 14 стандартом по умолчанию является `scram-sha-256`. Старые версии php-клиента в phppgadmin поддерживают только `md5`. Решение: флаг `-c password_encryption=md5` и использование ветки PostgreSQL 13 LTS.
2. **параметр `extra_login_security`:** по умолчанию phppgadmin блокирует вход под системным суперпользователем `postgres` без пароля или при стандартных настройках. Решение: явный проброс `PHP_PG_ADMIN_EXTRA_LOGIN_SECURITY=false`.

Благодаря этим двум директивам сервис работает на 100% стабильно и пропускать задание не требуется.

## запуск и проверка

```bash
docker compose up -d
docker compose ps
curl -I http://localhost:4482
```
