# файловый менеджер filebrowser (задание 6)

контейнеризованный веб-менеджер файлов на базе `filebrowser/filebrowser:v2.32.0-alpine`.

## особенности реализации

• **уникальный внешний порт:** опубликован на порту `4444` (`${FILEBROWSER_PORT:-4444}`) для предотвращения конфликтов с другими студентами на многопользовательском сервере.  
• **права доступа:** запуск от `user: "${UID:-1000}:${GID:-1000}"` предотвращает создание файлов от имени `root` в директории `srv/` на хосте.  
• **изоляция сети:** выделенный bridge `vipkc_filebrowser_net`.

## запуск и проверка

```bash
docker compose up -d
docker compose ps
curl -I http://localhost:4444
```
