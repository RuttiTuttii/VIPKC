# развертывание flame dashboard (задание 5)

панель управления и запуска приложений flame (`pawelmalak/flame:2.3.1`).

## ключевые решения

• **безопасное монтирование сокета Docker:** сокет хоста `/var/run/docker.sock` смонтирован с флагом `:ro` (read-only). Это исключает возможность повышения привилегий или управления демоном docker изнутри контейнера в случае компрометации.  
• **защита доступа:** парольная аутентификация через переменную `PASSWORD` и шифрование сессий через `SESSION_SECRET`.  
• **изоляция сети:** выделенная bridge-сеть `vipkc_flame_net`.

## запуск

```bash
docker compose up -d
docker compose ps
curl -I http://localhost:5005
```
