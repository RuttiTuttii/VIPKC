# связка phpmyadmin + mysql с сетевой изоляцией (задание 7)

проект демонстрирует организацию двухзвенной защищенной инфраструктуры:
1. `mysql-server` размещен в закрытой сети `pma_db_internal` (`internal: true`). База данных принципиально не имеет доступа в Интернет и закрыта от внешней локальной сети хоста (порт 3306 не публикуется).
2. `phpmyadmin` находится на стыке двух сетей: `pma_public_net` (принимает подключения пользователей на уникальном порту `4481`) и `pma_db_internal` (взаимодействует с СУБД по защищенному внутреннему каналу).

## запуск и проверка

```bash
docker compose up -d
docker compose ps
curl -I http://localhost:4481
docker network inspect vipkc_pma_db_internal
```
