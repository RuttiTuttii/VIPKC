# проект 2048 (задание 3)

контейнеризация статической веб-игры 2048 на базе собственного реестра образов (`ruttituttii/2048:1.0.0`).

## ключевые особенности

• образ оптимизирован до минимума (~20 МБ) с использованием `nginx:1.27.4-alpine3.21-slim`.  
• настроен встроенный эндпоинт `/healthz` для проверки жизнеспособности контейнера.  
• жесткие ограничения по памяти (128 МБ) и ядрам ЦП (0.50).  
• изолированная bridge-сеть `vipkc_game_net` со статическим пулом IP (`172.28.10.0/24`).  

## запуск

```bash
docker compose up -d
curl -I http://localhost:8080
```
