# подготовка ресурсов и переменных окружения (задания 1 и 2)

в этом каталоге реализованы требования пунктов 1 и 2 лабораторной работы:
1. изменение пользовательских переменных окружения, используемых docker (`DOCKER_BUILDKIT`, `COMPOSE_DOCKER_CLI_BUILD`, `COMPOSE_PROJECT_NAME`).
2. проброс переменных текущего пользователя хоста (`USER`, `UID`, `GID`, `TIMEZONE`) для безопасного запуска сервисов без root-прав.

## запуск настройки

```bash
chmod +x setup_env.sh
./setup_env.sh
```

## назначение переменных

• `DOCKER_BUILDKIT=1` — активация современного движка сборки BuildKit (параллельная сборка этапов, улучшенное кэширование).  
• `COMPOSE_DOCKER_CLI_BUILD=1` — интеграция BuildKit при сборке через `docker compose build`.  
• `COMPOSE_PROJECT_NAME` — явный префикс имен контейнеров, сетей и томов, предотвращающий конфликты.  
• `UID` и `GID` — передаются в сервисы (например, FileBrowser), чтобы файлы, созданные контейнером на хосте, принадлежали текущему пользователю, а не пользователю root.
