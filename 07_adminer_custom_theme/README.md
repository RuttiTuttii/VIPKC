# adminer + субд mariadb с кастомной темой (задания 9 и 10)

проект включает развертывание легковесного менеджера СУБД Adminer в связке с MariaDB, сетевую изоляцию базы данных и смену оформления интерфейса (скина).

## смена скинчика (задание 10)

согласно официальной документации Adminer на DockerHub и репозиторию GitHub `vrana/adminer`:
1. **способ через том (volume mount):** монтирование любого файла темы в путь `/var/www/html/adminer.css:ro`. В проекте подключена стильная темная тема `rmsoft_blue-dark` (`themes/adminer.css`), также в папке доступна альтернативная плоская тема `pappu687.css`.
2. **способ через Dockerfile (build):** сборка собственного образа через `Dockerfile`, где нужный CSS копируется внутрь контейнера.

## сетевая изоляция (задание 9)

• `adminer_db_internal` (`internal: true`) — СУБД изолирована от внешнего мира и хоста (порт 3306 не опубликован).  
• `adminer_public_net` — доступ к Adminer предоставлен на уникальном порту `4483` (`${ADMINER_PORT:-4483}`).

## запуск и проверка

```bash
docker compose up -d
docker compose ps
curl -I http://localhost:4483
```
